# Обновление «Академия Бионит — управление назначениями»

## Что добавлено
- `/academy-admin` — отдельная страница управления назначениями.
- `GET /api/admin/academy` — список активных сотрудников, активных курсов и последних 100 назначений.
- `POST /api/admin/academy` — ручное назначение курсов через RPC `academy_create_assignment`.
- `PATCH /api/admin/academy` — отмена назначения через RPC `academy_cancel_assignment`.
- Ссылка «Академия HR» появляется в навигации только если RPC `is_academy_admin()` вернул `true`.

## Защита
Каждый API-запрос повторно проверяет `is_academy_admin()` с пользовательским access token. Service Role Key не используется. Доступ к данным дополнительно ограничивается действующими RLS-политиками и SECURITY DEFINER RPC-функциями Supabase.

## Важно перед публикацией
1. Убедиться, что `NEXT_PUBLIC_DEMO_MODE=false`.
2. Убедиться, что SQL-функции `is_academy_admin`, `academy_create_assignment`, `academy_cancel_assignment` существуют и выданы authenticated.
3. Проверить, что политика чтения `profiles` разрешает администратору Академии видеть активных сотрудников компании.
4. Проверить, что RLS-политики чтения `learning_assignments` и `learning_assignment_courses` разрешают администратору Академии видеть назначения компании.
5. Сначала проверить на тестовой учётной записи администратора Академии и тестовом сотруднике.

## Ограничения текущей версии
- Управление делегированными правами пока не включено в интерфейс; выдача прав выполняется через имеющуюся RPC `academy_set_permission`.
- Список курсов содержит только активные `learning_classes`.
- Список назначений показывает последние 100 записей.
- Повторное назначение курса с существующим `learning_enrollments` использует существующую строку зачисления. Полноценный повторный цикл после статуса `passed` требует отдельной модели попыток/зачислений и не реализован этим UI.
- Это не подтверждает юридически значимое обучение по охране труда и не заменяет протоколы/практическую проверку.

## Проверка
Изменённые TS/TSX-файлы проверены на синтаксический разбор TypeScript. Полная `npm run typecheck` / `npm run build` в этой среде не выполнена: зависимости проекта не были установлены.

## Дополнительная SQL-защита
Перед первым реальным назначением применить `supabase/migrations/0006_academy_assignment_guard.sql`. Она запрещает повторное активное назначение того же курса тому же сотруднику и сразу помечает назначение завершённым, если все выбранные курсы уже имеют успешное прохождение. Изменение не удаляет и не переписывает старые попытки.
