# Академия Бионит — отчёт HR по обучению

## Что добавлено

- HR-отчёт по каждому курсу в каждом назначении.
- Фильтры по сотруднику, подразделению и статусу.
- Прогресс по фактически отмеченным учебным модулям.
- Лучший результат теста, использованные попытки и лимит попыток.
- Даты назначения, начала, срока и завершения.
- Экспорт текущей выборки в CSV с UTF-8 BOM и разделителем `;` (открывается в Excel).
- Кнопка «Отметить как изученный» в учебном модуле сотрудника.
- Серверная функция `complete_learning_module`, которая проверяет действующее назначение до записи прогресса.
- Серверная функция `get_academy_learning_report`, доступная только владельцу Академии и пользователям с `academy_admin`.

## Порядок внедрения

1. Сделать резервную копию Supabase.
2. В Supabase SQL Editor выполнить `supabase/migrations/0007_academy_learning_report.sql` целиком.
3. Убедиться, что запрос завершился `Success`.
4. Обновить файлы проекта из архива в корне репозитория (не помещать их во вложенную папку).
5. Отправить изменения в `main` и дождаться Vercel deployment.
6. Войти в приложение как владелец Академии и проверить HR-отчёт.
7. Войти под тестовым сотрудником, открыть назначенный курс, отметить один модуль как изученный.
8. Вернуться в HR-кабинет, нажать «Обновить» и проверить прогресс.

## Важные оговорки

- Прогресс модуля фиксируется по явному нажатию сотрудника «Отметить как изученный». Это самоотметка изучения, а не независимое подтверждение фактического усвоения материала.
- Результат теста берётся из `learning_enrollments.best_score`; количество попыток — из `attempts_used`.
- Просрочка вычисляется по сроку назначения и текущей дате, если курс ещё не завершён и не отменён.
- Исторические зачисления, не связанные с новой записью назначения, в отчёт назначений не включаются и не изменяются.
- Полную сборку Next.js в среде подготовки выполнить не удалось из-за отсутствия доступного npm registry. Синтаксический разбор изменённых TS/TSX-файлов прошёл без ошибок. Требуется подтвердить сборку на Vercel.
